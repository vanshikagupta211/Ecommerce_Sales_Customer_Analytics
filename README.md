# E-Commerce Sales & Customer Analytics

## 📌 Project Overview

This project is an end-to-end Business Intelligence solution developed using SQL Server and Power BI to analyze e-commerce sales, customer behavior, product performance, and delivery operations.

The project covers the complete analytics workflow from data preparation and SQL analysis to data modeling, DAX development, and interactive Power BI reporting.

---

## 🎯 Business Problem

E-commerce businesses generate large volumes of transactional data across customers, orders, products, payments, and delivery operations.

The objective of this project is to transform this data into actionable insights around:

- Sales performance
- Customer behavior
- Product performance
- Revenue trends
- Delivery efficiency

---

## 📂 Dataset

Dataset: Brazilian E-Commerce Public Dataset by Olist

The analysis uses:

- Customers
- Orders
- Order Items
- Products
- Payments

The dataset contains approximately 99K orders covering 2016–2018.

> Raw dataset is not included in this repository. Please refer to the original dataset source.

## 📊 Power BI Dashboard

The Power BI report contains four analytical pages:

### 1. Executive Overview

Provides an overview of:

- Revenue
- Orders
- Customers
- AOV
- Product sales
- Freight
- Revenue trends
- Category performance
- Geographic performance

### 2. Customer Analytics

Analyzes:

- Customer segmentation
- Top customers
- Revenue per customer
- Customer distribution
- Customer behavior

### 3. Product & Revenue Analysis

Analyzes:

- Category revenue
- Product performance
- Revenue contribution
- Freight cost
- Monthly revenue trends

### 4. Delivery & Operational Analysis

Analyzes:

- Delivery time
- Late delivery percentage
- Order status
- Monthly order trends
- Operational performance
